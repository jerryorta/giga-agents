# Step 10 — Hybrid mode — detail

Use `"conditional"` when stories' Phase 6/7 verification requires `/giga-workflow:epic-cross-actor-test`, which needs two browser profiles and a human: `/giga-workflow:epic-loop` then pauses on those stories and ships the rest unattended. A story whose need is already known can carry `crossActor: true` (or a scenario string) or `crossActor: false` in its front matter, and that overrides the loop's triage. A story that follows an established pattern (no new design, shared primitive or cross-library refactor) can carry an optional `model: sonnet` (or `opus` / `haiku`), which `/giga-workflow:epic-loop` uses for that story's agent. Surface a one-line note in the Step 13 summary so the user knows to hand-edit the field if the epic actually needs hybrid mode.
